# GOSH USH

Web pemesanan antar-jemput motor untuk sivitas akademika Universitas Sugeng Hartono,
dengan autentikasi Supabase, tarif berdasarkan zona, pembayaran QRIS, dan panel admin.

## Mulai

Ikuti [CARA-PAKAI.md](./CARA-PAKAI.md) untuk mengonfigurasi Supabase, menjalankan skema
dan migrasi database, membuat admin, serta menerbitkan web.

Mode demo masih tersedia di kode untuk preview, tetapi dinonaktifkan secara default.
